# Noted

A free, open-source, self-hosted app for notes, reminders, and time tracking. You write notes the way you'd send chat messages, and they stay organized in projects and channels.

Bring a server and your devices, and keep everything in one place. A domain is optional.

## What it does

- **Notes as messages:** channels for quick thoughts, threads, journals, documents, and tasks, with Markdown formatting.
- **Reminders:** messages that come back when you need them, as notifications on every device.
- **Time tracking:** one tracker for what you're doing now, plus a calendar for planned activities.
- **Your own server:** your data stays on your VPS. The Windows app installs Noted on it for you.

## Where it runs

- Web browsers
- Windows
- Android
- Wear OS 6
